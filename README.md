# ДЕЛО

Демонстрационный MVP Mini App для подбора мер поддержки малому бизнесу Санкт-Петербурга. Пользователь заполняет профиль, получает объяснимый ранжированный список программ, формирует план и получает тестовое уведомление через адаптер MAX.

## Быстрый запуск

```bash
copy .env.example .env
docker compose up --build
```

Откройте http://localhost:5173. В development включен локальный demo user и `MockMaxClient`: уведомления сохраняются в базе и видны в интерфейсе. API: http://localhost:8000/docs.

## Проверки

```bash
docker compose exec backend pytest
docker compose exec frontend npm run build
```

Для автоматизированной проверки API в корне есть `DATA-API.yaml` и `openapi.yaml`. Перед публикацией замените `https://delo.example.org` на фактический HTTPS-адрес backend и `teamId` на идентификатор команды.

## Ограничения

Каталог содержит демонстрационные данные, а не юридически значимые условия. Реальная интеграция MAX требует зарегистрированных бота и Mini App, публичного HTTPS URL и `MAX_TOKEN`; токен остается только на backend. `RealMaxClient` намеренно возвращает безопасную конфигурационную ошибку до подключения актуального официального SDK/API.

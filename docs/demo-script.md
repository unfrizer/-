# Demo script

1. Запустите `docker compose up --build` и откройте `http://localhost:5173`.
2. Заполните профиль ИП из Санкт-Петербурга: 3 сотрудника, 18 месяцев, цель «Оборудование».
3. На главной откройте лучшую рекомендацию: «Субсидия на оборудование» должна иметь высокий score и объяснение условий.
4. Нажмите «Подготовить заявку». В «Планах» появится чек-лист и будет создано mock-уведомление.
5. Отметьте пункты чек-листа; прогресс сохраняется после обновления страницы.
